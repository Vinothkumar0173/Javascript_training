1. What is a variable in JavaScript?
A variable is like a container used to store a value. In JavaScript, we can create variables using three keywords: var, let, and const.

2. What are the three keywords used to create variables?
The three keywords are:
1.	var
2.	let
3.	const

3. Write the syntax to create a variable using var.
var a = 25;

4. Write the syntax to create a variable using let.
let b = 30;

5. Write the syntax to create a variable using const.
const c = 200;

6. What is declaration?
Declaration means creating a variable without giving it a value.
Example:
let age;

7. What is initialization?
Initialization means assigning a value to a variable.
Example:
let age = 25;
Here, 25 is assigned to the variable age.

8. What is reassignment?
Reassignment means changing the value of an existing variable.
Example:
let age = 25;
age = 30;
The value of age is changed from 25 to 30.

9. What is redeclaration?
Redeclaration means declaring the same variable again in the same scope.
Example:
var name = "John";
var name = "David";

10. Which keyword allows redeclaration?
The var keyword allows redeclaration.

11. Which keywords allow reassignment?
Both var and let allow reassignment.
Example:
let age = 25;
age = 30;

12. Which keyword requires initialization when declared?
The const keyword must be initialized when it is declared.
Example:
const pi = 3.14;

13. Identify the declaration and initialization in this statement.

age = 25;

37. Can a const variable be reassigned?
No, a const variable cannot be reassigned.

38. Can a const variable be redeclared?
No, a const variable cannot be redeclared in the same scope.

39. What is wrong with this code?

43. Which keyword should you use if the value should not be reassigned?
We should use the const keyword when a variable should not be reassigned.

44. What is the difference between let and const?
The main difference is that let can be reassigned, while const cannot be reassigned.
A let variable does not have to be initialized immediately, but a const variable must be initialized when it is declared.
Neither let nor const can be redeclared in the same scope.

45. What is the difference between var and const?
The main difference is that var can be reassigned and redeclared, while const cannot be reassigned or redeclared.
Also, a const variable must be initialized when it is declared.

48. What is the purpose of console.warn()?
console.warn() is used to display a warning message in the browser console.
Example:
console.warn("This is a warning");

49. What is the purpose of console.error()?
console.error() is used to display an error message in the browser console.
Example:
console.error("Something went wrong");

50. What is the purpose of each?
alert()
alert() displays a message to the user in a popup box.
alert("Hello");
prompt()
prompt() asks the user to enter some information.
prompt("Enter your name");
confirm()
confirm() asks the user to confirm an action. It returns true when the user clicks OK and false when the user clicks Cancel.
confirm("Are you sure?");
document.writeln()
document.writeln() writes content directly to the webpage.
document.writeln("Hello World");
console.log()
console.log() displays information or values in the browser console. It is mainly used for checking values and debugging.
console.log("Hello World");
